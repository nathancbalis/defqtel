Classification Method

Awards are classified using Anthropic's Claude AI. Each award title is analyzed and assigned to one or more categories in each dimension based on semantic understanding of the content.

Claude 3 Haiku
Success Rate
99.8% (17,233 of 17,265)

Why AI classification?

  • → Semantic understanding captures context beyond keyword matching
  • → Consistent classification criteria across all 17,265 awards
  • → Ability to assign multiple categories when appropriate
  • → Handles domain-specific terminology and acronyms

Limitations

1. Title-based classification. Analysis is based on award titles only. Full abstracts are not consistently available in the source data.
2. AI classification accuracy. While the model achieves high consistency, some edge cases may be misclassified. Classification is frequently checked.
3. Category boundaries. Some technologies span multiple categories. The classification reflects the primary focus of each award.
4. SBIR scope. SBIR awards represent early-stage R&D investments and do not capture total DoD technology spending.
5. Classified programs. Awards for classified programs may have generic or obscured titles, affecting classification accuracy.

Data Updates

Data is manually refreshed from SBIR.gov on a periodic basis. The current dataset includes awards through December 2024. Classification is re-run when new data is added to ensure consistency across the full dataset.
